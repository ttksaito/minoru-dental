# SEO / AIEO 対策タスク（みのる歯科サイト向け）

作成: 2026-10-19
元資料: `SEOとAIEO対策に関する実務調査報告.md`（一般論の調査報告）を、当サイトの実装・運用状況に当てはめて整理したもの。

## 方針（報告書の結論をこのサイトでどう扱うか）

- 既存SEOの基盤（クロール・インデックス・構造化データ・サイトマップ）の上にAI検索対策を乗せる。別プロジェクトにしない。
- `llms.txt`、AI検索専用schema、AI検出器スコアは**やらない**（Google公式が不要と明記。検出器は精度・偏りの問題あり）。
- 歯科＝医療情報（YMYL）。品質KPIは「重大誤り0件」「重要な主張は出典で裏付け」「院長監修済み」の3つ。
- 独自価値は「東松山の実際の医院として、院長の臨床経験・判断を書く」こと。一般論の要約記事は増やしても効果が薄い。

  「当院でよくある相談」「実際の治療の流れ」など、一般論の要約では書けない記事。AI検索でも通常検索でも独自性として評価される方向。

## やらないこと

- `llms.txt` の設置、AI検索専用の構造化データ
- AI検出器のスコアを下げる文章調整
- 下書きの大量生成・大量公開（scaled content abuse のリスク。監修の手が追いつかない）
- 他サイト記事の言い換えによる記事作成
