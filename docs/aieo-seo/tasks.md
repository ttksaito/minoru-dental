# SEO / AIEO 対策タスク（みのる歯科サイト向け）

作成: 2026-10-19
元資料: `SEOとAIEO対策に関する実務調査報告.md`（一般論の調査報告）を、当サイトの実装・運用状況に当てはめて整理したもの。

## 方針（報告書の結論をこのサイトでどう扱うか）

- 既存SEOの基盤（クロール・インデックス・構造化データ・サイトマップ）の上にAI検索対策を乗せる。別プロジェクトにしない。
- `llms.txt`、AI検索専用schema、AI検出器スコアは**やらない**（Google公式が不要と明記。検出器は精度・偏りの問題あり）。
- 歯科＝医療情報（YMYL）。品質KPIは「重大誤り0件」「医学的な主張は公的機関・学会など一次情報で裏付け」の2つ。院長監修フローは置かない（2026-10-19 方針変更）。
- 執筆はサイト運営者（院長の次男。非医療従事者、MBA・博士後期、数学が得意）が単独で進める。院長が関与する記事は最小限にし、関与した記事だけ `author: 院長` にする。
- 独自価値は「患者の立場」「数字・データの読み解き」「意思決定・習慣化の話」「医院の裏側・地域情報」。歯科医が書く一般論の要約とは差別化する。文体は堅苦しくしない。

## タスク一覧

### P0: 計測の基準値と制作ルールを作る（1か月以内）

- [ ] **Search Console を本番ドメインで確認する**
  `https://www.minoru-dental.jp` のプロパティが有効か確認し、`sitemap.xml` を送信。インデックス状況とカバレッジのエラーを記録する。「生成AIパフォーマンスレポート」が表示されるかも確認（段階展開中）。
  完了条件: 全7URLがインデックス済み、現在のクリック/表示回数を記録。
- [ ] **Bing Webmaster Tools に登録する**
  Search Consoleからのインポートで登録可能。「AI Performance」で Copilot からの引用（Total Citations / Grounding Queries）を見られるようにする。
  完了条件: サイト検証済み、sitemap送信済み。
- [ ] **GA4 でAI経由の流入を分けて見られるようにする**
  参照元 `chatgpt.com`、`perplexity.ai`、`copilot.microsoft.com`、`gemini.google.com` をカスタムチャネルグループ「AI検索」にまとめる。
  完了条件: 探索レポートでAI検索チャネルを月次で確認できる。
- [ ] **基準値を記録する**
  上記3つの数値（検索クリック・表示・AI流入）を `docs/aieo-seo/` に月次で追記する表を作る。最初の1行が基準値。
- [ ] **運営者向けの公開前セルフチェックを決める**
  院長監修の代わりに、運営者自身が公開前に確認する項目を短く決める。
  - 医学的な断定（診断・治療効果・薬や処置の是非）をしていないか。する場合は一次情報へのリンクがあるか
  - 数値・固有名詞は原典を開いて確認したか
  - 治療効果の保証、他院との比較、体験談の扱いなど医療広告ガイドラインに触れる表現がないか
  - summary・タグ・サムネイル・出典があるか
  完了条件: `docs/aieo-seo/self-check.md` として保存し、CMSの下書きのヒントから参照する。
- [ ] **下書き9本の扱いを決める**
  いずれもAI草稿で医学的な内容が中心。運営者の視点（患者目線・数字の読み方）を足して公開するか、題材だけ残して書き直すかを1本ずつ判断する。公開するものは出典を付ける。
- [ ] **運営者だけで書けるテーマを10本程度リストにする**
  例: 初めての歯医者で聞くことリスト、保険と自費の違いを図で整理、「総入れ歯は噛む力11%」の数字の読み方、「リスク2倍」の相対と絶対、定期検診の費用対効果、歯医者を先延ばしにする理由と対策、当院の予約から会計までの流れ、東松山で歯が痛くなったら。
  完了条件: `docs/aieo-seo/topics.md`。

## やらないこと

- `llms.txt` の設置、AI検索専用の構造化データ
- AI検出器のスコアを下げる文章調整
- 下書きの大量生成・大量公開（scaled content abuse のリスク。監修の手が追いつかない）
- 他サイト記事の言い換えによる記事作成
