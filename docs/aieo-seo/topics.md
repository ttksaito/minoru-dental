## 1. 初めて（久しぶりに）歯医者に行く前に、聞いておくと楽になる質問リスト

- **一言で**: 診察室で「何を聞けばいいか分からない」をなくす、患者側のチェックリスト。
- **想定する検索**: 歯医者 初めて 何を聞く / 歯医者 久しぶり 怖い / 歯医者 質問 リスト
- **骨子**
  - 行く前に整理しておくこと（いつから・どこが・どんなとき痛むか、服用中の薬、妊娠の有無、過去に嫌だった経験）
  - 診察室で聞いていい質問の例（治療は何回くらいか、今日は何をするか、痛みが出たらどうするか、費用の目安は聞いていいか）
  - 当院の初診の流れ（問診票 → カウンセリング → 検査 → 治療計画の説明 → 同意後に治療開始）に沿って「どのタイミングで聞くか」
  - 聞きにくいことの伝え方（「削るのが怖い」「麻酔が苦手」は最初に言っていい）
- **根拠**: 当院の初診の流れ（トップページ記載）。医学的主張は不要。
- **注意**: 「痛くない」「必ず〜できる」のような効果の保証表現は使わない。

## 2. 東松山市の歯科健診と補助制度、まとめてみた

- **一言で**: 市の乳幼児歯科健診、妊婦歯科健診、成人・高齢者向け歯科健診、後期高齢者の歯科健診など、使える制度を一覧に。
- **想定する検索**: 東松山市 歯科健診 / 東松山 妊婦 歯科 無料 / 東松山市 子ども 歯科 補助
- **骨子**
  - 年齢・対象別の一覧表（対象、時期、費用、申し込み方法、問い合わせ先）
  - 当院で受けられるものがあればその旨（受託医療機関かどうかは医院に確認）
  - 「どの制度を使えば次の受診を無料・安くできるか」の見方
- **根拠**: 東松山市公式サイト、埼玉県の歯科保健のページ。すべて公開情報。制度は年度で変わるので `updated` を使って更新する。
- **注意**: 制度の内容は必ず市のページを開いて確認し、リンクを付ける。地域名を含む検索に強く、AI検索でも引用されやすい一次情報の整理になる。

## 3. 「総入れ歯は噛む力が11%」はどう読む？ 研究の数字を読み解く

- **一言で**: 公開済み記事「入れ歯になると、どのくらい噛めなくなる？」の数字を、研究の読み方という切り口で深掘りする。
- **想定する検索**: 入れ歯 噛む力 何パーセント / 総入れ歯 噛む力 研究 / 咬合力 天然歯 比較
- **骨子**
  - 「100%・80%・35%・11%」が何を測った数字か（最大咬合力か、咀嚼能率か、対象者は誰か）
  - 平均値の落とし穴（個人差の幅、分布の形）
  - 「11%でも食べられる」が矛盾しない理由（噛む力と食べられる物の関係は比例しない）
  - 数字を見るときの3つの質問（何を測った、誰を測った、幅はどれくらい）
- **根拠**: 公開済み記事が参照している文献［1］〜［3］を特定して、記事末尾に出典として明記する。元の下書きに出典がないので、ここで必ず補う。
- **注意**: 治療方針（インプラントが良い等）には踏み込まない。

## 4. 定期検診は「割に合う」のか。時間とお金で考えてみた

- **一言で**: 検診の費用と時間を、治療になった場合の費用・通院回数と比べる試算記事。
- **想定する検索**: 歯科 定期検診 費用 / 定期検診 意味ある / 歯医者 定期検診 頻度 お金
- **骨子**
  - 検診1回のコスト（保険3割負担の目安、移動と待ち時間）
  - 虫歯・歯周病が進んだ場合の通院回数と費用の目安
  - 「年に何回行けば元が取れるか」の簡単な損益分岐の考え方
  - 試算の前提と限界（人によって違う、費用は変わる）を正直に書く
- **根拠**: 厚生労働省の診療報酬点数（公開）、歯科疾患実態調査、8020推進財団の資料。定期受診と医療費の関係を示す研究があれば引用（要確認。見つからなければ試算だけにする）。
- **注意**: 当院の具体的な料金は書かない（書くなら院長確認が必要になる）。一般的な保険点数ベースの「目安」にとどめる。

## 5. 保険診療と自費診療、何が違う？ 仕組みを図で整理

- **一言で**: 「保険が効く・効かない」の仕組みと、選ぶときの考え方を患者側から整理する。
- **想定する検索**: 歯医者 保険 自費 違い / 自費診療 なぜ高い / 保険診療 範囲 歯科
- **骨子**
  - 保険診療の仕組み（国が決めた範囲と点数、3割負担）
  - 自費診療の仕組み（医院が料金を決める、材料や方法の自由度）
  - 混合診療の基本的なルール
  - 選ぶときに聞くべきこと（何が違うのか、保険で済む選択肢はあるか）
- **根拠**: 厚生労働省、日本歯科医師会の公開ページ。
- **注意**: 自費治療の優位性や料金には触れない（医療広告ガイドラインの対象になりやすい）。制度の説明に徹する。

## 6. 歯医者でよく聞く言葉、ざっくり翻訳します（インレー・クラウン・根管治療…）

- **一言で**: 診察室で飛び交う用語を、患者側の言葉に言い換えた用語集。定義の紹介に徹する。
- **想定する検索**: インレー とは / 根管治療 とは わかりやすく / 歯医者 用語 意味 / スケーリング 何
- **骨子**
  - 「詰める・被せる」系（インレー、アンレー、クラウン、ブリッジ、仮歯）
  - 「神経」系（根管治療、抜髄、歯髄）
  - 「掃除」系（スケーリング、PMTC、歯石）
  - 「検査」系（レントゲン、歯周ポケット検査、○mm）
  - 一覧表＋それぞれ2〜3行の説明。治療の良し悪しや適応には触れない
- **根拠**: 日本歯科医師会「歯とお口のことなら何でもわかる テーマパーク8020」、日本歯科保存学会などの公開用語解説。
- **注意**: 定義だけ書く。「この治療が良い」「この症状ならこれ」は書かない。用語ごとに見出しを分けると、AI検索の回答にそのまま引用されやすい形になる。

## 7. 日本人の歯は何歳で何本残っている？ 歯科疾患実態調査の数字を読む

- **一言で**: 厚労省の統計から「年齢別の残存歯数」「8020達成率の推移」「失われやすい歯」を表とグラフで読み解く。
- **想定する検索**: 日本人 歯 何本 平均 年齢 / 8020 達成率 / 歯 残る本数 60代 / 歯科疾患実態調査
- **骨子**
  - 年齢階級別の平均残存歯数（最新と20年前の比較）
  - 8020達成率の推移と、何が変わったか
  - 最初に失われやすい歯（奥歯から、という傾向）
  - 統計の読み方の注意（調査方法の変更、サンプル、平均と分布）
  - 「自分の年齢で平均より多い・少ない」を見るためのセルフチェック表
- **根拠**: 厚生労働省「歯科疾患実態調査」（公開統計）、8020推進財団の資料。数値は原典の表を開いて転記する。
- **注意**: 歯を失う原因の医学的説明には深入りしない。データの読み方を主役にする。運営者の数字の強みがそのまま出る記事。

## 8. 歯の治療費は医療費控除になる？ 対象になるもの・ならないものを整理

- **一言で**: 確定申告の医療費控除で、歯科の費用がどこまで対象かを国税庁の情報で整理する。
- **想定する検索**: 歯科 医療費控除 / 矯正 医療費控除 大人 / セラミック 医療費控除 / 歯医者 交通費 医療費控除
- **骨子**
  - 医療費控除の基本（年間10万円または所得の5%を超えた分、家族合算、年末調整では不可）
  - 歯科で対象になるもの（保険診療、一般的な自費の補綴、子どもの矯正、通院の交通費）
  - 対象にならない・条件付きのもの（美容目的のホワイトニング、大人の矯正の扱い、自家用車のガソリン代・駐車場代）
  - 手続きの流れ（領収書の保管、医療費通知、e-Tax）
  - ざっくり還付額の計算例（所得税率別の表）
- **根拠**: 国税庁タックスアンサー「医療費控除の対象となる医療費」「歯の治療費」、国税庁の確定申告ページ。
- **注意**: 税務の個別判断は書かない（「不明な場合は税務署へ」）。当院の料金は書かない。確定申告期（1〜3月）の前に公開すると検索が伸びる。

## 9. 休日や夜に歯が痛くなったら。東松山・比企地域の救急歯科の調べ方

- **想定する検索**: 東松山 休日 歯医者 / 埼玉 夜間 歯科 救急 / 日曜 歯が痛い どこ / 比企 休日急患 歯科
- **骨子**
  - まず連絡する窓口（埼玉県の救急電話相談、東松山市・比企地区の休日急患の案内）
  - 休日歯科診療の仕組み（当番医制、受付時間、持ち物）

  - 翌診療日に当院へ連絡するときの案内（受付時間、電話、LINE）
- **根拠**: 埼玉県公式サイト、東松山市公式サイト、比企地区歯科医師会の公開情報。当番医や電話番号は必ず原典へリンクし、`updated` で更新する。
- **注意**: 応急処置（痛み止めの服用、冷やす等）は書かない。「連絡先の案内」に徹する。地域名を含む検索で強く、AI検索でも「どこに連絡するか」の回答に引用されやすい。

## 10. 学校歯科健診の紙の「CO」「GO」って何？ 親向けの読み方ガイド

- **一言で**: 学校から持ち帰る歯科健診結果の記号を、公的な定義に沿って翻訳する。
- **想定する検索**: 歯科健診 CO とは / 学校 歯科検診 GO 意味 / 歯科健診 要観察 どうする / 歯科検診 紙 見方
- **骨子**
  - 記号の意味の一覧（C、CO、G、GO、×、○、歯列・咬合・顎関節の欄）
  - 「要観察（CO・GO）」と「要受診」の違い
  - 紙をもらったあとの流れ（受診勧告の紙、受診報告書の提出）
  - よくある疑問（COは治療するのか、様子見でいいのか → 判断は歯科医院に委ねると明記）
  - 東松山市の学校歯科健診の時期があれば記載（2本目の記事と連携）
- **根拠**: 日本学校歯科医会、文部科学省「児童生徒等の健康診断マニュアル」の公開資料。
- **注意**: 「COなら治療不要」のような判断は書かない。定義と流れの説明に徹する。保護者の検索が多く、毎年6月前後に需要が集まる。

## 書くときの共通ルール（セルフチェック用の仮置き）

- 医学的な断定（診断、治療効果、薬や処置の是非）はしない。必要なら一次情報へリンクする。
- 数値・固有名詞は原典を開いて確認し、記事末尾に「参考」として並べる。
- 治療効果の保証、他院との比較、患者の体験談の引用は避ける（医療広告ガイドライン）。
- 当院の料金は書かない。制度や目安の話にとどめる。
- 文体はですます調のまま、一人称と質問形タイトルは自由。
