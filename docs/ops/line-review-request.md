# 公式 LINE からクチコミ（Google レビュー）を依頼するフロー — 設計中（2026-11-15）

## 再開用のプロンプト

```
docs/ops/line-review-request.md を読んで、クチコミ依頼フローの続きを進めて。クチコミのリンクは［ここに貼る］、公式 LINE の使い方は［LINE で予約のやり取りをしている／友だち追加だけで予約は電話が中心］。
```

## 背景
- Google ビジネスプロフィールのクチコミは 3 件（★5.0）。同名の別医院「みのる歯科 浮間舟渡」（東京都板橋区、226 件）と「みのる歯科」検索で取り違えられやすい
- マップ経由の接点（管理パネルの「顧客による操作」514 回）はサイト訪問より大幅に多く、クチコミ数は来院判断に直結する
- 運営者の希望: 公式 LINE（https://lin.ee/zFdXAeb）から依頼するフローを作りたい

## 守るルール（必ず守る）
- 全員に同じように依頼する。満足した人だけを選んで送る「レビューゲーティング」は Google のポリシー違反
- 特典・割引・景品と引き換えにしない。★の数を指定・誘導しない
- スタッフ・家族・関係者に書かせない
- クチコミを自院サイトに転載しない（医療広告ガイドラインで患者の体験談の掲載は制限）。Google 上にあるだけなら問題ない
- 依頼文に電話番号は入れて構わない（LINE は投稿ポリシーの対象外）。ただしビジネスプロフィールの「投稿」本文には電話番号を書かない

## フロー案
1. **リッチメニューに「クチコミを書く」を常設**（依頼しなくても書きたい人が押せる）
2. **来院後のお礼メッセージで依頼**。どちらにするかは LINE の使い方次第
   - A. 個別送信: LINE で予約をやり取りした患者に、受付が定型文をトークで送る（LINE 公式アカウントの「定型文」に登録）
   - B. タグで一斉送信: 受付が来院者のトークに「来院済」タグ → 週 1 回そのタグのオーディエンスに配信 → 送信後にタグを外す
3. **リンクはサイトの短い URL 経由**: `https://www.minoru-dental.jp/review` → GA4 イベント `review_click` を送ってから Google のクチコミ画面へ転送。クチコミ画面を開いた数を GA4・ダッシュボードで数えられる
