# GA4 キーイベント登録の仕上げ（2026-11-15）

## カレンダーのプロンプト

```
docs/ops/2026-11-15-ga4-key-events.md を読んで続きを進めて。GA4 の星は［押した／まだ一覧に出てこない］。
```

## 背景（2026-11-14 時点）

- サイト全ページに、電話番号・LINE・地図リンクのクリックを GA4 へ送る仕組みを入れた（イベント名 `tel_click` / `line_click` / `map_click`）。index.html と templates/ の gtag 直後にある
- スマホ（携帯回線）からのタップが GA4 リアルタイムに届くことは確認済み。運営者の PC は GA4 の除外設定で届かない
- GA4 側で「キーイベント」として登録するのは運営者の手作業: 管理 → データの表示 → イベント → 「最近のイベント」タブ → 各イベントの左の星を押す
- 星を押せるのはイベントが一度でも届いた後（数時間〜24 時間で一覧に出る）

## Claude がやること

### 「押した」と言われた場合
1. `gh workflow run update-dashboard.yml` を実行し、完了後 `git pull` → 復号スクリプトで `ga4.keyEvents` に tel_click 等が入っているか確認する（登録直後は件数 0 でも正常。登録前に起きたクリックは遡って数えられない）
2. ダッシュボードの「成果につながる行動」と Google 広告の「キーイベント」列が表示されることを確認する
3. 次のステップ（TODO の 3 番）を案内する: Google 広告 → 目標 → コンバージョン → 概要 → 「+ 新しいコンバージョン アクション」→「インポート」→「Google アナリティクス 4 プロパティ」→「ウェブ」→ `tel_click` と `line_click` を選んでインポート。これで広告が「電話した人」に最適化される
4. TODO.md の 1 番を完了にし、3 番の手順を具体化する

### 「まだ出てこない」と言われた場合
1. 原因は「まだ誰もクリックしていない」か「GA4 の反映待ち」。運営者がスマホ（Wi-Fi オフ）でもう一度タップするよう案内する
2. 反映には最大 24 時間。翌日に再確認するカレンダー予定を 1 件作る（同じプロンプトを本文に入れる）
