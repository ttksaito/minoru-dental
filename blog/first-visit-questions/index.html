初めて（久しぶりに）歯医者に行く前に、聞いておくと楽になる質問リスト

公開日: 2026年10月20日
歯の豆知識

歯医者に行く前って、少し気が重くないですか。私は院長の息子ですが、それでも「久しぶりに行くと何を言われるんだろう」と身構えます。

この記事は、診察室で「何を聞けばよかったんだろう」と帰り道に思わないための質問リストです。治療の中身の話ではなく、「聞いていいこと」と「聞くタイミング」の話なので、どの歯医者に行く方にも使えると思います。

行く前に、手元で整理しておくこと

診察室に入ると、意外と頭が真っ白になります。スマホのメモに次の5つを書いておくと、問診票もカウンセリングもスムーズです。

  • いつから、どこが、どんなときに気になるか（例：2週間前から、右下の奥歯が、冷たいものを飲むとしみる）
  • 飲んでいる薬やサプリ（お薬手帳があれば持っていくのが一番楽です）
  • 持病や通院中の病気、妊娠中・授乳中かどうか
  • 過去に歯医者で嫌だったこと（麻酔が効きにくかった、音が苦手、長く口を開けるのがつらい、など）
  • 今日どこまで希望するか（とにかく痛みを何とかしたい、まず状態だけ知りたい、など）

特に4つ目は、言わないと伝わりません。「怖がりです」と最初に言っておくと、その前提で進めてもらえます。

ちなみに、みのる歯科ではこのメモをそのままLINEで送っていただいても大丈夫です。予約のやり取りのついでに「2週間前から右下の奥歯がしみます。麻酔が苦手です」と一言添えてもらえれば、当日その前提で受付からお迎えできます。口で説明するのが苦手な方には、こちらのほうが楽かもしれません。

受診の流れと、それぞれの場面で聞いていいこと

みのる歯科の初診は、おおよそ「受付・問診票 → カウンセリング → 検査 → 治療計画の説明 → 同意のうえで治療開始」という流れです。多くの歯科医院も大きくは同じだと思います。場面ごとに、聞いていい質問を並べます。

受付・問診票のとき

  • 今日はどのくらい時間がかかりそうですか
  • 保険証（マイナ保険証）以外に必要なものはありますか
  • 次の予定があるので、○時までに終わりたいのですが大丈夫ですか

時間の希望は、受付の段階で言っておくのが一番確実です。

カウンセリングのとき

ここが一番、整理したメモが役に立つ場面です。

  • 気になっていることを全部話していいですか（複数あっても大丈夫です）
  • 今日はどこまで診てもらえますか
  • 昔の治療で嫌だったことがあるのですが、配慮してもらえますか

検査のあと、治療計画の説明のとき

  • 今の状態は、急ぐものですか、様子を見てもいいものですか
  • 治療は何回くらい、どのくらいの期間かかりそうですか
  • 選択肢はいくつかありますか。それぞれの違いは何ですか
  • 保険でできる方法と、そうでない方法がありますか
  • 費用の目安はどのくらいですか

費用を聞くのは、まったく失礼ではありません。むしろ先に聞いておくほうが、お互いに進めやすいはずです。

治療が始まる前・途中で

  • 痛かったら、どうやって合図すればいいですか
  • 途中で休憩をお願いしてもいいですか
  • 今日の治療が終わったあと、気をつけることはありますか

「痛かったら左手を上げてください」のような合図を先に決めておくと、安心して口を開けていられます。

言いにくいことの伝え方

「こんなこと言ったら面倒な患者だと思われないかな」と心配する方は多いと思います。でも、医院側からすると、先に言ってもらえるほうが助かります。言い方の例をいくつか。

  • 「削る音が苦手なので、始める前に一声かけてもらえますか」
  • 「麻酔が効きにくいと言われたことがあります」
  • 「嘔吐反射が強くて、型取りが苦手です」
  • 「今日は説明だけ聞いて、治療は次回から考えたいです」

最後のひとつは、特に久しぶりに行く方に覚えておいてほしい言い方です。「今日は状態を知りたいだけ」という受診は、ごく普通のことです。

帰る前に確認しておくこと

  • 次回の予約はいつで、何をする予定か
  • 今日の治療のあと、食事や歯磨きで気をつけることはあるか
  • 痛みが出たときの連絡先と、連絡していい時間帯

この3つを聞いて帰ると、家に着いてから「あれ、どうすればいいんだっけ」がなくなります。

まとめ：質問は、準備しておくほど楽になる

歯医者で緊張するのは普通のことで、質問を準備しておくこと自体が、緊張を減らしてくれます。

  • 行く前に「いつから・どこが・どんなとき」「薬」「過去に嫌だったこと」「今日の希望」をメモする（LINEで先に送ってもOK）
  • 時間の希望は受付で、怖いことや苦手なことはカウンセリングで、費用や回数は治療計画の説明のときに聞く
  • 「今日は説明だけ」も、ちゃんとした受診のかたち

みのる歯科では、お電話（0493-24-9080）のほか、LINEでもご予約やお問い合わせを受け付けています。上で書いたメモをLINEで先に送っていただくのも歓迎です。「こういうことが不安なのですが」という相談から始めていただいて大丈夫です。
