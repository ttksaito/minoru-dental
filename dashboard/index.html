用語の説明

ユーザー / セッション / 表示回数（GA4）
ユーザーはサイトに来た人数、セッションは訪問回数、表示回数はページが見られた回数です。1人が2回来て3ページ見ると、1・2・3になります。
エンゲージメント率（GA4）
10秒以上見た・2ページ以上見た・キーイベントが起きた、のいずれかに当てはまる訪問の割合。すぐ離脱されていないかの目安です。
表示回数 / クリック数 / CTR / 平均掲載順位（Search Console）
Google の検索結果に出た回数と、そこからクリックされた回数。CTR はクリック÷表示。平均掲載順位は検索結果で何番目に出たかの平均で、小さいほど上位です。
流入チャネル
Organic Search＝検索から、Direct＝URL直打ちやブックマーク、Referral＝他サイトのリンク、Paid Search＝Google 広告、Organic Social＝SNS、Unassigned＝判別できなかったもの。
キーイベント
電話番号のタップや予約ページの閲覧など、GA4 で「成果」として設定した行動。未設定だとここは空になります。
